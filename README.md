# 🎯 Number Guessing Game

My first Python project! A simple command-line game where the computer generates a random number and the player tries to guess it.

## 🚀 Features

- Random number generation (1–100)
- Higher or lower hints
- Maximum 5 attempts per round
- Tracks the number of attempts
- Replay option
- Case-insensitive replay input

## 🛠️ Technologies Used

- Python 3
- Random module
- VS Code

## ▶️ How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python main.py
```
